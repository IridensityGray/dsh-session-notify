# 对话停止提醒

同时开着多个 Harness 任务时，不必再逐个点开确认状态：任何会话一停下来，这里就会提醒你。

## 触发时机

| 提醒 | 什么时候 |
|---|---|
| 等你选择 | 助手调用了提问工具，弹出需要你点选的选项 |
| 等你授权 | 权限/审批提示正在等你决定 |
| 已完成 | 一轮任务结束（助手停止运行） |
| 等你输入 | 会话空闲超过设定时长仍没有新输入 |
| 出错 / 中断 | 这一轮以错误结束，或被中止 / 触发输出上限 |

默认监控**所有工作区、所有会话**，包括子任务与定时任务会话。

## 提醒形式

1. **屏幕小卡片**：右上角最多叠 4 张，显示提醒类型、会话名和摘要；点「查看」跳到该会话，点「×」关闭，2 分钟自动消失。
2. **Windows 通知 + 提示音**：窗口在后台时也能看到；声音是一声短提示音。
3. 侧栏底部的**铃铛**上有未读数量，点开是设置面板。

## 设置

侧栏底部铃铛 → 设置面板：

- 每种提醒单独开关。
- 空闲多久后提醒（默认 5 分钟）。
- 「只在窗口不在前台时提醒」：默认开启，你正看着窗口时不打扰。
- 「只提醒当前没在看的会话」：正在看的会话即使切到后台也不提醒。
- 关闭小卡片（只留系统通知和声音）。
- 四个「测试」按钮，立刻验证卡片、通知和声音。

## 限制

- 通知与声音由 Host 侧通过 PowerShell 发出，需要 Windows 桌面版；纯网页版（浏览器打开 `dsh web`）只能显示卡片。
- Windows 首次使用时会在开始菜单创建「Harness Notify」快捷方式，用来登记通知身份。
- 侧边栏收起成窄条时只显示铃铛图标与数字角标。
- 提醒在同一会话的同一轮里只触发一次，避免重复打扰。
- Harness 完全关闭后没有代码在监听会话，关闭时正在跑的任务不会补发提醒。

## 安装

```sh
dsh plugin --profile <profile> add @iridensity_gray/dsh-session-notify
```

安装后重启 Harness，Host 侧才会挂载。
